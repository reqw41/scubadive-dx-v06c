# ЧЕМ НАШ РИСУНОК ОТЛИЧАЕТСЯ ОТ АВТОРСКОГО

Порт идёт дословно по источнику, и каждое отступление от рисунка Зимина
записано здесь поимённо — чтобы любое из них можно было отыграть назад.
Мест два.

## 1. Выравнивание зеркальных наборов — 16 пикселей

Наборы кадров для движения влево не хранятся, а получаются отражением набора
для движения вправо (1976 байт, см. docs/mirror_sets.md). Наборы совпадают не
байт в байт: в двенадцати местах у автора подрисовано вручную. Решение
владельца 2026-09-01 — не тратить байты на заплатки, выравнивать зеркалом.

Полный список — `docs/mirror_sets.md`, он же печатается замером:
`node tools/verify/mirror_census.js <каталог сборки>`

## 2. Силуэт вместо сплошного блока в стайке — 12 пикселей

В кадрах стайки (Fish cloud) шесть особей нарисованы сплошным блоком 4x2 —
восемь пикселей без формы. Пока вся стая была одного цвета, блок читался как
рябь; когда каждая особь получила своё чернило, он стал читаться как кирпич.

Из восьми пикселей снимаются два, и остаётся профиль рыбки — хвост слева,
тело справа, как у крупных особей того же кадра (они плывут вправо):

```
   было      стало
   ####      #.##
   ####      .###
```

Мелочь в один-три пикселя не трогается вовсе: рыбку в двух пикселях не
нарисовать, поэтому она осталась и по форме, и по цвету прежней — жёлтой.

Снятые пиксели (смещение кадра в блоке L7748, строка, пиксель в строке):

```
ПРАВКА ФОРМЫ (сплошной блок 4x2 -> силуэт), снято 12 пикселей:
  кадр +0: строка 21, пиксель 3
  кадр +0: строка 22, пиксель 2
  кадр +72: строка 22, пиксель 3
  кадр +72: строка 23, пиксель 2
  кадр +144: строка 21, пиксель 4
  кадр +144: строка 22, пиксель 3
  кадр +289: строка 21, пиксель 4
  кадр +289: строка 22, пиксель 3
  кадр +361: строка 22, пиксель 4
  кадр +361: строка 23, пиксель 3
  кадр +433: строка 21, пиксель 5
  кадр +433: строка 22, пиксель 4
упакованные маски D 186 Б + таблица 32 Б = 218 Б сверх нынешних данных
```

Список печатает сам генератор при каждом запуске:
`node tools/cloud/mkcloudink.js <каталог сборки>`
