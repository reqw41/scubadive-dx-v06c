# ЗЕРКАЛЬНЫЕ НАБОРЫ КАДРОВ: 1976 БАЙТ, КОТОРЫЕ ЛЕЖАТ ДВАЖДЫ

Набор кадров для движения влево есть зеркало набора для движения вправо.
Замер — `tools/verify/mirror_census.js`, он же печатает список ниже заново.

## Фазы совпадают, это не анимация

Каждый кадр сверен с КАЖДЫМ кадром зеркального набора, а не только с
одноимённым. Расхождение в пикселях, Shark:

```
            зеркало кадра 0    1    2    3
   кадр0                 0  161   67  172
   кадр1               161    0  180  245
   кадр2                66  181    1  140
   кадр3               172  245  141    0
```

Диагональ 0-1, вне её 66-245. У остальных типов так же: по диагонали 0-2,
вне её 27-322. Сдвига фаз нет, наборы соответствуют кадр в кадр.

## Решение владельца 2026-09-01

**Заплатки не хранить, выравнивать зеркалом.** Двенадцать байт разницы — это
единичные точки на кромке хвоста или щупальца, в разных кадрах в разных
местах; ни одна не похожа на осмысленную асимметрию (не глаз, не плавник).
По виду это ручная доводка автора после офлайн-отражения или артефакт его
инструмента поворота. Сорок восемь байт таблицы заплаток дороже, чем эти
шестнадцать пикселей.

**ЭТО ЕДИНСТВЕННОЕ МЕСТО, ГДЕ МЫ ОТСТУПАЕМ ОТ РИСУНКА АВТОРА.** Поэтому список
ниже — не справка, а обязательство: по нему правку можно отыграть назад
в любой день, добавив таблицу заплаток.
