РЕЦЕПТ HEADLESS-ЗАМЕРА ZX-ОРИГИНАЛА В MAME (0.289)

Зачем: калибровать темп нашего порта под ИГРУ 1983 ГОДА, а не под порт Зимина.
Метки порта nzeemin (LExxx) — это адреса ZX-оригинала, поэтому точки счёта
известны без разбора кода: LD9C0=0xD9C0 (игровой цикл), LB213=0xB213 (вызывается
раз за итерацию И в игре, И в демо), LE2A8=0xE2A8 (ныряльщик — только в игре).

Запуск:
  SDL_VIDEODRIVER=dummy mame spectrum -rompath <roms> \
    -cass "Scuba Dive.tzx" -autoboot_script tempo.lua \
    -nothrottle -video none -sound none -seconds_to_run 900
ПЗУ: spectrum.rom = zx48.rom, sha1 5ea7c2b824672e914525d1d5c419d71b84a426a2
(лежит в ~/projects/humphrey-v06c/roms/zx48.rom). Fuse не нужен.
SDL_VIDEODRIVER=dummy ОБЯЗАТЕЛЕН — иначе окно отбирает фокус.

ЧЕТЫРЕ ГРАБЛИ, каждая стоила отдельного захода:
1. Подписки (add_*_notifier, install_read_tap) НАДО держать в живой переменной.
   Локальная умирает вместе со скриптом, сборщик мусора снимает подписку, и
   колбэк перестаёт вызываться через несколько кадров. Симптом: первая печать
   вышла, дальше тишина. Лечится _G.frame_sub = emu.add_...
2. Поле ioport надо выставлять КАЖДЫЙ КАДР всё время удержания: система ввода
   MAME пересчитывает поля покадрово и затирает разовый set_value.
3. Бейсик не принимает клавиши примерно до 250-го кадра после сброса. Раньше —
   нажатия уходят в пустоту. Проверено kbtest.lua: при нажатии с 200-го кадра
   строка 0xBFFE уходит bf->b7 (бит 3 = J), LAST-K(0x5C08)=0xEF = токен LOAD.
   Ни -autoboot_command, ни natkeyboard:post (даже с -natural) до Бейсика не
   доходят вовсе — грузить только матрицей.
4. LOAD "" = клавиша J (режим ключевых слов), затем дважды SYMBOL SHIFT+P, затем
   ENTER; после этого ЛЕНТУ НАДО ПУСТИТЬ САМОМУ: cass:play(), иначе стоит.

Проверка редакции (обязательна перед замером) — байты по адресам меток:
  0xD9C0: cd 13 b2 cd ea bd cd a8 e2   (CALL LB213 / CALL LBDEA / CALL LE2A8)
  0xB213: cd c0 b2                     (CALL LB2C0)
  0xE2A8: dd 21 3b                     (LD IX,DiverObj, DiverObj=LE33B)
Совпало с нашим src_ref — редакция та же.

5. ГЛАВНАЯ: emu.add_machine_reset_notifier НЕ СРАБАТЫВАЕТ — autoboot_script
   запускается уже ПОСЛЕ сброса машины, колбэк не зовётся никогда. Все tap'ы,
   которые я ставил внутри него, не ставились вовсе; отсюда «счётчик молчит»,
   которое я ошибочно списал на то, что tap не ловит опкодную выборку. Ставить
   tap НА ПЕРВОМ КАДРЕ. Проверка: taptest.lua даёт 59686 выборок 0x15E1 за 200
   кадров (холостой цикл ПЗУ).
6. Пространство для выборки команды — "opcodes", не "program".
7. Демо-режим выходит в меню по ЛЮБОЙ клавише: жать один раз и больше не трогать,
   иначе игра так и стоит в меню (PC приклеен к 0xEE2F).

ЗАМЕР (сцена с существами, демо-режим, окна по 5 с):
  134.2 / 242.0 / 189.8 / 176.4 / 156.0 / 177.2 тика в секунду, среднее ~179.
  При 50 Гц это 2.7-4.8 тика на кадр, обычно 3.1-3.8.

ФАЙЛЫ: tempo.lua — загрузка + замер; zxload.lua — только загрузка;
kbtest.lua — доходит ли нажатие до порта 0xFE; ports.lua — опись портов и полей;
spaces.lua — какие адресные пространства есть у процессора.
